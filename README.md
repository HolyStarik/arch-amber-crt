# Arch Amber CRT

Неофициальная янтарная CRT-тема для Arch Linux с настроением Bitcoin-терминала. Визуальные приёмы — крупная типографика, моноширинные подписи, тонкие рамки и терминальные метки — вдохновлены [crestapp.xyz](https://crestapp.xyz/). Проект не связан с Crest.

## Что получится

- Hyprland с тонкими янтарными рамками, мягким свечением и спокойными анимациями.
- Waybar и Wofi в чёрно-янтарной палитре.
- Тёмные SVG-обои с символом ₿.
- При входе в Hyprland открывается полноэкранный `cool-retro-term`: заставка показывает BTC/USD, затем клавиша открывает shell.
- Цена запрашивается у публичной точки Coinbase Spot без API-ключа. Это котировка Coinbase, а не усреднённая цена всего рынка. Без сети появится сообщение о недоступности цены.
- Янтарный prompt для Bash.

## Установка на Arch Linux

Сначала установи Hyprland и настрой вход в сессию Hyprland. Затем клонируй свой репозиторий и запусти установщик:

```bash
git clone https://github.com/ТВОЙ-USERNAME/arch-amber-crt.git ~/arch-amber-crt
cd ~/arch-amber-crt
bash install.sh
```

Установщик поставит пакеты через `pacman`, сделает резервные копии конфликтующих Waybar/Wofi конфигов и подключит тему. Существующий `hyprland.conf` сохранится: в него добавится `source` темы, а исходная версия будет скопирована в файл с суффиксом `.bak.<дата-время>`. После установки выйди из Hyprland и войди снова.

Если у тебя уже есть собственные бинды Hyprland, проверь возможные пересечения в `hypr/appearance.conf`. Видеокарты NVIDIA могут потребовать отдельной настройки Hyprland.

## Подстройка cool-retro-term

При первом запуске открой настройки `cool-retro-term`, выбери янтарный профиль (если он есть в установленной версии) и отрегулируй scanlines, glow и curvature на свой вкус. Программа сохраняет профиль отдельно от конфигов этой темы.

## Файлы

- `install.sh` — установка пакетов, резервное копирование и подключение конфигов.
- `hypr/appearance.conf` — визуальные настройки и автозапуск заставки.
- `scripts/bitcoin-splash.sh` и `scripts/btc-price.py` — экран входа и цена BTC/USD.
- `waybar/`, `wofi/`, `bash/` — палитра панели, меню и prompt.
- `assets/amber-grid.svg` — обои.
- `packages.txt` — список пакетов.

## Ручной запуск заставки

```bash
bash scripts/bitcoin-splash.sh
```
